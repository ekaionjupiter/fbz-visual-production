## Key takeaways

**Tools / stack named**
- Claude Code running **Fable 5** (title says Fable 5.1) as the builder; **Three.js** ("3.js") for the 3D orb / scroll environment.
- **Higgsfield** via its **MCP** plugged into Claude Code (Claude Code > Customize > Connectors > Add custom connector > paste Higgsfield MCP/CLI string > OAuth sign-in). Referral: https://higgsfield.ai/s/mcp-liamottley-SfAEQx
- Higgsfield models Claude tested for image-to-video: **Veo 3.1 Ultra** (more movement) vs **Cinema Studio 3.0** (chosen; asked for colour-corrected, "post-production" vlog look).
- **Mobbin** (~$20/mo) via MCP: finished websites from big brands, pulls code/structure as grounding for UI.
- **21st.dev** (~$9/mo) via MCP: searchable component library (used to find spheres/globes/orbs).
- **Firecrawl** replaces Claude Code's default web scraping (used to scrape Osprey docs).
- **Osprey** (osprey.ai, backed by Albacross) visitor-identity resolution: ~40% of US traffic resolved to name/email/LinkedIn/phone, 80-85% accurate; $0.18 AI enrichment per lead; ICP scoring; webhooks to CRM, **Instantly**, **Expandi** for outbound. Site: ai-makeover.io.
- Pricing/hooks: "AI Makeover" business, https://bit.ly/aimakeover

**Workflow (step by step)**
1. Define audience/personas first (business owners, sponsors, AI agency owners/consultants) and tell Claude Code who the site is for.
2. Concept before code: brainstorm with Claude; researched 3D sites on Twitter/web; landed on a "living intelligence" orb with data sources plugging in. Concept is "the most difficult part for many of you".
3. Media is the gap between "vibe coding slop" and premium: collect real photos/footage; where footage missing, use Higgsfield to outpaint portrait stills to 16:9 then image-to-video them.
4. Prompt pattern given to Claude Code (verbatim): "Hey, I have these photos, here they are, this is the location that they are on my machine. Can you please explore all of the Higgsfield MCP and figure out what we can do with it? I'd like to turn a bunch of these into widened, as if they were 16x9 footage." Then: "Please do an exploration, figure out which models are going to work the best." Claude compared models autonomously.
5. Build with three grounding sources: Mobbin + 21st.dev (MCP) + Three.js examples.
6. Iteration pattern (verbatim): "give me 10 different concepts. Okay, then review the 10 concepts. Okay, I like that one, give me five more like that in different variations." Repeated per section (orb, makeover cards, method section, sponsors, about).
7. ~2 days of build; separate mobile-optimisation pass afterwards (heavy 3D design "mobile suffers for sure").
8. Deploy, scrape Osprey docs with Firecrawl, paste script snippet + domain, verify capture.

**Anti-AI-slop rules (explicit)**
- Slop sites = "a bunch of boxes and icons and text and headings" with minimal custom media and "AI slop style copy".
- Two things that make a site stand out: (1) the copy, hand-attended marketing language; (2) custom photos/video/media of you/your business. "either way you have to have media of your own".
- Trade-off: flashy design can hurt conversion; simpler pages often convert better, so backstop with lead-capture tooling.

**Images / motion / compositing**
- Outpaint vertical stills to widescreen, then animate; ask the model for colour correction so clips match real vlog footage.
- Prefer more movement (Veo 3.1 Ultra) if you want life; Cinema Studio for a cleaner graded look.
- Site motion: scroll-triggered blur/burn transition to a pulsing dot, 3D orb with mouse hover effect, swipeable media cards mixing moving and still images.
