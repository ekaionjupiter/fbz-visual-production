## Key takeaways

### Thesis
- The "$10K" feel comes from a scroll-driven hero video: "The whole page moves along with you, almost like it's telling you a story." Examples: coffee pours into the cup as you scroll; a perfume drop falls and transforms into the bottle; a tech site pulls you through a field of purple light; a jeans brand where you "sew the stitching into the jeans yourself" by scrolling.
- Sites must still load fast and work on mobile; the skill handles research, copy, build, and deployment.
- Three tools: Claude (Claude Code via desktop app), Higgsfield (image + video generation via MCP connector), Hostinger (hosting via Hostinger Connector MCP).

### Models / plans named

- "The newest and most powerful model is called Fable, and Fable is what makes the best looking sites." Fable needs the Max plan ($100+/mo) or pay-as-you-go credits; occasional Pro promotions. "Pro and Opus build you a great site. Max or Credits gets you Fable and the best possible result."

### Setup workflow (step-by-step)
1. claude.ai → create account → Pro or Max → install Claude Desktop app → sign in → switch to the **Code** tab.
2. Bottom right: set model (Fable if available) and **drag the effort slider all the way right** ("the strongest Claude model with the highest effort available").
3. Folder icon → Open folder → create a new empty workspace folder (e.g. "10K websites demo").
4. Set permission mode to **auto mode** so Claude does not ask at every step.
5. Connect Higgsfield: sign up with credits (a $0 one-day trial was offered) → Higgsfield "MCP and CLI" page → copy the URL → Claude Code "+" → Connectors → Manage connectors → Add → Add custom connector → name "Higgsfield", paste URL → Add → Connect → browser OAuth → Allow → Open link.
6. Download the free "10K Website Skill" (Google Drive zip) and drag it into the workspace folder.
7. First prompt, verbatim: "Use the 10K websites skill to build me a website for my coffee brand."

### The skill's intake questions (what the skill asks)
- Brand status: brand new idea / real shop with photos / real shop with no photos (or free text).
- Vibe: "warm, calm, and handcrafted", "dark and dramatic", "bright and playful", or "clean and minimal".
- References: "surprise me" or drop in websites/images/real photos.
- Assets: logo, product photos, other files (drop into chat) or "make everything from scratch".
- Scroll-video concept: skill proposes concepts tuned for scroll-scrubbing (coffee: "espresso pull" recommended, pour-over, beans falling) or a custom idea.
- Brand name (recommended or custom).

### Asset generation workflow (Higgsfield via MCP)
1. Claude prompts Higgsfield for the **starting frame** of the hero video (the first thing visitors see); reviewer approves or asks for changes ("use this frame").
2. Claude asks which **video model** to use, with credit cost; author picks Seedance. Video generation takes a few minutes.
3. Review video; Claude reports regenerate cost and remaining credits; "use this video".
4. Claude then generates **additional section imagery** (three images in the demo); approve with "use these images".
5. Full build takes "anywhere from like 20 minutes all the way to over an hour" depending on complexity.

### Review / revision workflow
- The in-app preview panel "doesn't work super well"; open the localhost link in a real browser instead.
- Do a single pass through the whole site, note every change (cut-off text, remove a reviews section, replace an image).
- Use voice-to-text and plain language; "Just think of Claude like your personal website developer." Verbatim revision prompt: "I noticed as I was scrolling through the website, the second block of text in the hero section seems to be weirdly cut off. I need you to take a look at that and make sure it's fixed. Also, I think I want the fonts to be more bold. I'd also like you to do a final quality pass and make sure that everything appears correct on the website."
- Then choose "get it online" from the skill's options.

### Deployment workflow (Hostinger Connector)
- Hostinger Business plan, 12-month term (free domain first year; demo domain emberlinecoffeeshop.com), skip hPanel onboarding, Domains → Set up → register → verify email.
- Hostinger Connector page → Install extension → select Claude Code → copy snippet → paste into Claude Code and send → browser OAuth → Allow. If the OAuth page does not open, restart the Claude desktop app and ask Claude to open it.
- Claude asks whether to use the claimed domain ("yes, use my domain"), deploys, connects DNS. Future changes are pushed live by chatting with Claude Code. Check on mobile after launch. hPanel "Ask AI" (Kodee) for hosting questions.

### Design / anti-slop notes
- The scroll-scrubbed hero video (image → video from a start frame, then scrubbed by scroll position) is positioned as the single element that makes sites "feel expensive".
- Skill gates intake on real photos, logos and references before generating anything; AI-generated visuals are the fallback for brand-new ideas, not the default for real businesses.
- Concept choice for scroll video should be physically continuous top-to-bottom (pour, drop, falling beans, stitching) so scroll progress maps to a motion.
- Fonts revisited at review time ("more bold"); always run "a final quality pass".
- Mobile check is a required release step.
