### The seven levels (workflow)
1. **Grab and go** - chatbot-style prompt ("Claude, build me a website, please"). Produces the "classic AI website design feel": floating product, nothing creative. Anti-pattern.
2. **Screenshots and references** - "show, not tell". Mood-board from Godly, Land-book, Awwwards, Dribbble (search e.g. "dashboard", studios like Halo Lab), copy image, drop into chat. Prompt: "Hey there, I'd like you to update the website using this image as a reference style for how I'd like the website to look."
3. **Design skills** - prepackaged instructions that explain "This is exactly how you create great design. This is what a website should look like. This is what a website should not look like." Install by pasting the GitHub URL: "Hey, I want to go ahead, check out this skill, then download it, and add it to your skills." Named skills: Anthropic frontend-design, UI UX Pro Max ("67 UI styles, 161 color palettes, font pairings"), shadcn/ui skill, Awesome Design Skills, GSAP skills, plus Jack's own "power design" skill (slides research that "applies to websites as well"). Build prompt: "I'd like to use all the best skills and design principles to build me a beautiful website selling yellow iPhones... Make sure that using all relevant skills that I've given you for building beautiful design." Also attach a screenshot reference "for good measure". Result: brand logo, centralized color palette, more on-brand font, Bento Box layout, named yellow shades (Daybreak, Canary, Sunshine, Honey, Amber).
4. **Image and video** - "giving our wonderful artist tools". OpenArt settings: Nano Banana 2, aspect 21:9 for wide hero shots, 2K resolution ("No need for 4K, 1K is way too low"), generate 2-4 variants, iterate (e.g. swap to white background). Connect image generators to Claude Code via MCP so Claude builds all assets programmatically: "go build me this website and generate for me beautiful images that will slot in and be relevant." Video from a frame: OpenArt video tab, Kling/Seedance 2.0, start frame = product image, prompt "This is a product shot. Please rotate this phone for the video.", enhanced prompt on, 16:9, set duration/size, and **use the same image as end frame** so the loop "lands in the exact same location" (seamless loop for web hero video).
5. **UI snapping (sniping)** - copy production-grade components from 21st.dev (check "Featured"), CodePen, Magic UI, Mobbin. Copy code or URL and prompt: "Hey there, I'd like you to integrate this balloons feature at the bottom of the page." Don't re-engineer the wheel.
6. **Data** - "a beautiful website that does not actually turn viewers into buyers... is like having a Ferrari with no engine." Firecrawl MCP extracts brand identity (logos, typography, color scheme): "go to apple.com and use my Firecrawl integration... grab me the brand identity and then just upgrade this website in accordance with that." Competitive research prompt (verbatim core): "I'm launching a roofing business in Leeds in the UK... find for me the 10 most successful roofing businesses in London and... 10 ones that are not doing very well... comprehensive research in terms of what do the winners have that the losers do not? What do they have in common? What is the order of their website? Do they all have an image and then a CTA? What is the CTA?... come up with a scoring matrix to determine what a great website is and isn't. The output... is a clear blueprint that I can pass to another model... Everything must be evidenced and if required... cross-validate this with a different model. Make sure that you use the Firecrawl MCP to do that research."
7. **Design extraction** (strongest) - "talk to the architect". Ask Claude to extract a site's design identity (typography, colors, general design rules, spacing/white-space, ratios) into a blueprint, then rebuild better. Reference site used: antigravity.google ("one page, one thought... interactivity, but it doesn't distract"). Jack uses a "Design Blueprint Extractor" skill from his community; DIY version: "Hey, I want you to be able to create a blueprint and verify this so that I can do anything I need to." Build prompt: "I'm going to give you a website. I would like to basically understand the design, and I'd like you to follow all the instructions in this file. Namely, go to this website, understand the typography, the design, and get it an extraction blueprint so that I can build a website that levels this up. And our website is going to be on selling beautiful phones." Result with Fable 5 in one shot: named brand, dynamically color-shifting orb, strong typography.

### Anti-AI-slop rules extracted
- Never prompt without references; the "classic AI website design feel" = floating product on gradient, generic layout, generic font.
- Skills must encode both what a site should and should not look like.
- Images: wide (21:9) 2K, multiple variants, programmatic generation via MCP so assets are relevant to each section rather than stock-like.
- Hero video: start frame = end frame for a seamless loop.
- Use real components (UI snapping) instead of Claude re-inventing interactions.
- Design must be evidenced by data (winners vs losers scoring matrix) and by extracted blueprints of sites that already work; "not copying, but looking at external data".
- Reference design qualities praised: one page/one thought, subtle interactivity that does not distract, crisp animation, ample white space, golden-ratio type relationships, Bento layouts, centralized palette.
