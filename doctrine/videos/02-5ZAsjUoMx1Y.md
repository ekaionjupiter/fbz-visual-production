## Key takeaways

### Tools / models named
- Claude Code with **Fable 5** for builds; **Sonnet** ("sonnet fire"/Sonnet 4.5 as heard) for minor edits.
- Pinterest for references; Figma used only as a moodboard/scratch canvas (not for editing); Figma's paid "edit with prompt" mentioned as an alternative image generator.
- **Higgsfield** for image generation and video; **Kling 3.0** ("clean 3.0") for image-to-video, 10 s, 1080p ("you don't really need 4K"); Seedance referenced for video-reference effects ("students" in captions).
- Google Fonts for font matching (found "Instrument Serif").
- CleanShot for screen recording a reference effect; any online background remover (don't need Figma's paid one).
- motionsites.ai (his prompt library of 200+ sites), designrocket.io.

### Workflow (step by step)
1. **References (20–30 min, "the most time consuming process")**: search Pinterest for "web design"; screenshot anything with good colors, layout, or graphics (quality irrelevant). Paste into Figma as a moodboard. Search for graphic motifs ("butterfly dark AI generated", "butterfly purple", "branch", "philosophy purple 3D object"). "We don't have to copy nothing... with AI we can just remix a lot of stuff together which would look unique."
2. **Remix a hero concept in Higgsfield** from 2–3 references. Prompt pattern: "In the first image... replace all of the content to be around meditation website... remove the navbar and also remove the image of the tree in the center. Just add the branch from the second and the third images across the whole hero section and keep it similar style to the second image but make the background... the same as in the first image." Only take layout/text positions from a reference, not content.
3. **Apply the color reference**: "make the tree branch the same kind of style texture as the second image and replace the whole background to be this dark gradient... turn the whole content into dark mode and do not add the yellow circle."
4. **Split the concept into two assets** so code can rebuild it: (a) "create me an image exactly like this in 4K/8K. Just remove all of the text, the buttons, the icons, the circles from the background. I just want to have the same absolute background without anything" (also "no logo"); (b) "create an image... with the text position the same way, remove the background leaving only the text and icons and a plain black background." The text-only image is a UI layout spec Claude "can build very simply without getting distracted."
5. **Identify fonts**: Claude "will get the fonts very wrong" from screenshots. Google-image-search "Google fonts best free fonts", visually compare to the reference, copy the font name.
6. **Build hero in Claude Code (Fable 5)**: "build me a hero section on a pure black background. Position the text and the content same as on the reference images and use this font [Instrument Serif], import it from Google fonts... import some icon library and put those three icons the same way as they position on the screenshot. Make sure everything is mobile responsive."
7. **Animate the background**: upscale image ("create an image like this in 8K highest resolution"), then image-to-video with "animate this. No zoom in or zoom out." Optional: screen-record a reference effect and prompt "animate the first image. Just take the effect from the second [video]. Do not take any colors, any elements from the second." Generate several videos and A/B them on the page. Audience note: energetic motion for 20–30 year olds, calmer for older.
8. **Add video**: "add this video to the background of our hero section. Do not add any overlay over the video." Then fix legibility: reduce all fonts 10–15%, headline 30%, remove useless dividers.
9. **Build the rest in one prompt**: alternating "chess format" feature cards (video left/text right, then swapped), three icon features, testimonials, footer; "for the headlines, use uppercase"; keep fonts consistent.
10. **Polish**: drop to two cards; "remove the stroke and the fill of the whole card... I just want to have the video and then the text"; different video URLs per card; "add white buttons under each description" ("Having buttons on the page is extremely important"); remove fills from testimonial cards, keep stroke; remove dividers before footer; equalize section spacing.
11. **Section dividers from generated art**: remove background from a generated branch image, test placement in Figma, then "add around 200 pixels top padding... I need a divider... absolute position on the middle of those two sections." Also a video with "pure black" background used as a divider between testimonials and footer with 200–300 px spacing.

### Anti-slop rules (explicit)
- AI "fills that are different from the background or the stroke" on cards are a tell; remove fills, keep at most a stroke.
- Unnecessary divider lines between sections are "really annoying"; remove.
- Fonts guessed by AI are wrong; identify and import the exact Google Font.
- Mobile: stack small label chips in one row, not three rows.
- Don't put overlays over hero video; fix legibility via type scale instead.
