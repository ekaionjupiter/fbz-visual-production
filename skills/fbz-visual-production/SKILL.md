# FBZ Visual Production

The bar: every shipped asset must look like it was built by a designer in Photoshop, layered and lit, not generated in one pass. Reference tiles: the Leonel Salas Figma (file `UVmXkMR8Qc57lPf6kJ3WE7`, node `7:233`, email headers + sales page). Full doctrine with sources: `doctrine/FBZ_Visual_Production_Doctrine.md`. Do not ask Kai questions about image quality; this skill already answers them.

## Hard rules (non-negotiable)

1. **Reference first.** Pull 3 refs per asset (LAYOUT, MOOD, OBJECT) before any generation. Template: `references/reference-library.md`. Log the source next to every ref. If no refs exist, take them from the Leonel file or the client's real photos. Never from a text prompt alone.
2. **Never one-shot.** 5 directions on one contact sheet, pick 1, 3 variants, pick 1, then tweak. Minimum 2 variants per plate. Score every candidate 1 to 5 against the refs; nothing under 4 ships.
3. **Plates from the model, type and logo from code.** The image model never renders a word, a number, a button or the emblem. Prompts for plates end with: "No text, no logos, no UI, no watermark."
4. **Split every reference composite** into plate (4K, no UI) + cutout (subject on pure black, then alpha) + layout (wireframe on black): `scripts/split_reference.py`.
5. **Layer order, always:** plate → grade → light → emblem with depth → type band → grain 3 to 5% → vignette. Built with `scripts/composite.py <spec.json>` or as named layers in Figma. One light treatment per asset. One warm accent per view.
6. **Named fonts only.** Read the brand tokens file; use the exact family and weight (FBZ calm brands: Fraunces + DM Sans in `fonts/`). Never Inter. Never a default font. If the client font is unknown, identify it first (Google Fonts / Fontshare / Fonts In Use) and name it in the spec.
7. **Real beats generated.** Use the client's real photos, logo, product, people and data when they exist. Products the model invents get squished; supply the real product image as an OBJECT reference. Never generate a person's face when a real photo exists.
8. **Resolution:** 2K for stills and section art, 4K only for plates that will be cropped or upscaled. Headers 1800x600, feed ads 1080x1350, story ads 1080x1920, hero 2688x1520 (16:9), covers 4:5.
9. **Compliance is a layer check.** Health niches: safe-sleep (baby on back, firm flat surface, nothing in the crib), no medical claims, no fake statistics. Regulated niches: no before/after. Reject and regenerate plates that break this; log rejections in `assets/ASSET-LOG.md`.
10. **Motion:** "animate this, no zoom in or zoom out"; name the one thing that must not move; one continuous take; start frame = end frame for loops; storyboard 9 frames before spending video credits.
11. **Banned tells (reject on sight):** Inter, purple/blue gradients, 3D SaaS blobs, glossy waxy skin, blown highlights, oversaturation, text or logos generated by the model, card fills that differ from the background, side-tab accent borders, eyebrow chip stacked over a giant headline, cartoon props for serious niches, countdown urgency, perfectly symmetrical "stock" faces, melting or warped type.
12. **Mandatory pre-ship scan:** `scripts/slop_check.sh <renders dir>` (Impeccable 61-rule detector on HTML + pixel checks on renders), then a side-by-side contact sheet against the reference tiles. Fix, re-run, then ship. Also run `/impeccable critique` on any page.
13. **Capture corrections.** When Kai says "I liked X / didn't like Y", add it to `references/corrections.md` as a rule and re-read that file before the next asset.

## Workflow (run this every time)

```
1. BRIEF      read brand tokens + copy; write intent (what / why / audience / action) + ALWAYS/NEVER lines
2. REFS       3 per asset into <client>/assets/refs/ with sources (reference-library.md)
3. PLATES     Higgsfield generate_image_batch: gpt_image_2_5 quality=high res=2k (stills), Nano Banana Pro (products/people),
              2 to 4 variants each, prompts from references/prompt-patterns.md, "no text no logo no UI"
4. REVIEW     contact sheet, compliance check, pick, log rejections
5. EMBLEM     clean SVG + depth render (image-to-image on the SVG PNG, "cannot change shape"), light + dark
6. COMPOSITE  one JSON spec per asset -> scripts/composite.py (plate, grade, light, emblem, type band, grain, vignette)
7. QA         scripts/slop_check.sh; side-by-side vs reference tiles; score 1..5; <4 goes back to step 3 or 6
8. SHIP       overwrite <client>/assets, rebuild HTML pages, rebind Figma image fills, push to Drive
9. LOG        assets/ASSET-LOG.md: model, job id, prompt, score, rejections, cost
```

## Higgsfield defaults
- Stills: `gpt_image_2_5`, `quality: high`, `resolution: 2k`, aspect from the asset table. 4 variants on contact sheet for heroes, 2 for plates.
- Products / people / UGC: Nano Banana Pro (original) via `models_explore` recommend; never GPT Image for faces.
- Image-to-image: `medias: [{role: image_references, value: <media_id>}]`; upload refs with `media_upload`/`media_import_url`.
- Video: Seedance 2.5 for motion graphics, Kling 3.0 for image-to-video loops. Storyboard first.
- Always `get_cost: true` once before a batch; log credits.

## Files
- `scripts/composite.py` JSON-spec compositor (Pillow). Supports variable fonts via `"weight"`.
- `scripts/split_reference.py` reference → plate/cutout/layout prompts + alpha matte.
- `scripts/slop_check.sh` Impeccable detect + render checks.
- `references/reference-library.md` ref slots per asset type.
- `references/prompt-patterns.md` verbatim prompts from the 14 videos.
- `references/corrections.md` Kai's standing corrections (read first).
- `fonts/` Fraunces + DM Sans variable TTFs.
- `examples/` spec files from the Lena Park build (copy and edit).

## Output protocol
Final message: `DONE`, then at most 2 sentences for anything needing Kai's attention, then any message he asked for. No essays.
