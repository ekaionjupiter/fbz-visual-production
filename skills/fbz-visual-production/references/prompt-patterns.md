# Prompt Patterns (reusable, from the 14-video doctrine)

Use these verbatim or with the bracketed slots filled. Source video in parentheses.

## Plates (image model makes the background only)
- "Create an image exactly like this reference in 4K. Same scene, lighting and grade. Remove ALL text, headlines, buttons, icons, logos, badges and circles. Keep only the photographic background. Extend the scene naturally where elements were removed." (02)
- "Editorial documentary photograph, shot on 35mm film, Kodak Portra 400, natural grain. [scene]. [palette]. Composition leaves calm negative space on the [side] for a headline. Real skin texture, lived-in room, shallow depth of field. No text, no logos, not stock-photo cheesy." (FBZ, proven on Lena Park)
- Outpaint: "Turn these portrait stills into widened, as if they were 16x9 footage." (07)
- Explore: "Explore all of the Higgsfield MCP and figure out which models are going to work the best for [task]." (07)

## Cutouts and layout references
- Cutout: "Isolate ONLY the main subject on a pure solid black background. No text, no logo, no floor shadow. Keep the exact shape, lighting and colors." (02, 03)
- Layout: "Keep the text position exactly the same way, remove the background, plain black background." (02)
- Remix: "Replace all content to be around [niche]. Remove the navbar. Add the [element] from the second and third images across the hero. Keep the background the same as the first image." (02)
- Color pass: "Apply this color reference: dark gradient, dark mode. Do not add the [unwanted element]." (02)

## Emblem / logo depth
- "Render this exact logo mark as a physical object: [brushed metal | glazed ceramic | enamel pin | foil stamp], soft studio rim light from the top-left, subtle [accent color] glow behind it, shallow shadow beneath. The mark CANNOT change shape, proportions, or letterforms. Pure solid black background, centered, 2K." (03 + 10 + FBZ)

## Products and people
- Product set: "Same room, new angles: a hand touching the product, a macro of the [material] texture, a wide establishing shot. The product keeps its exact shape." (14)
- UGC avatar (one-shot, never iterate): "[Reference still]. Change the person's identity enough that it could not be the same person. Keep the framing, lighting and background. Add [one outlier accessory]. Visible [mic | phone close]. Both hands visible. Shot on iPhone, real skin texture, pores, no glossy highlights." Nano Banana Pro original, not GPT Image. (11)

## Motion
- "Animate this. No zoom in or zoom out." (02)
- "[Object] keeps its exact shape and cannot shift position." (03)
- "Static locked off shot" / "Handheld UGC iPhone shot" / "One take, no jump cuts." (11)
- "Describe the outcome like a director to crew, not the technique: [the title] opens itself corner by corner in slow, deliberate stages and settles dead center." (03)
- Loop: "Use this same image as the end frame so the loop lands in the exact same location." (04)
- Storyboard first: "Generate a nine-frame storyboard for this video. We fix it at the image stage, then use it as the reference before rendering." (10)
- Beats: "Write it as four beats in the order they land: [beat 1], [beat 2], [beat 3], [beat 4]." (03)

## Selection and critique
- "Give me 10 different concepts. [pick] I like that one, give me five more like that in different variations." (07)
- "Generate 5 versions in 5 different aesthetic families on one screen." (01)
- "Compare it with [reference]. I want you to be ruthless. Output the breakdown as a concise HTML file." (09)
- "Go to this website, understand the typography, the design, and give me an extraction blueprint so I can build something that levels this up." (04)
- "Grab me the brand identity (logos, fonts, colors) and upgrade this in accordance with that." (04, 05 via Firecrawl)

## Web
- Hero: "Pure black background, position the text the same as the reference, use [named font] imported from Google Fonts, [icon library], mobile responsive." (02)
- Fix legibility: shrink headline 30%, body 10 to 15%. (02)
- "Nail the hero first, then the hero-to-body transition, then the body." (01)
- Final: "Do a final quality pass. Check mobile." (06)

## Skill capture
- "Create a skill for this process that we've just done." (14)
- "Update the skill: I really liked [X]. I really did not like [Y]." (12)
- "When I correct you, write the lesson into memory.md as a new rule and check it before every task." (14)

## Guardrail block (append to every brief)
ALWAYS: named fonts, real references, plate+type split, one light source, grain + vignette, side-by-side against the reference before shipping.
NEVER: Inter, purple gradients, 3D SaaS blobs, text or logos generated by the image model, card fills that differ from the background, eyebrow chips over giant headlines, side-tab accent borders, countdown urgency, oversaturated color.
